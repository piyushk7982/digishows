# DIGISHOWS — One Page Website

A premium, responsive one-page digital marketing agency website built with plain HTML, CSS and JavaScript.

## Files
- index.html — complete page structure/content
- style.css — responsive design, premium dark/purple UI and animations
- script.js — mobile menu, scroll reveal, cursor glow and WhatsApp contact form

## Quick setup
1. Upload all files to your hosting public_html folder.
2. Keep `index.html`, `style.css` and `script.js` in the same folder.
3. Open your domain.
4. Replace the text-based D logo with your actual logo when ready.
5. Replace the placeholder/brand details as needed.
